📘 Key Vocabulary Kosakata Kunci

Mapping PemetaanA mapping is a rule that changes one number (input) into another number (output).Pemetaan adalah aturan yang mengubah satu bilangan (masukan) menjadi bilangan lain (keluaran).
Domain & Range Domain & Range (Daerah Hasil)The domain is the set of all inputs \(x\). The range is the set of all outputs \(f(x)\). The output of \(x\) is called the image of \(x\).Domain adalah himpunan semua masukan \(x\). Range adalah himpunan semua keluaran \(f(x)\). Keluaran dari \(x\) disebut peta (image) dari \(x\).
Definition of a function Definisi fungsiA function is a mapping in which every input in the domain has exactly one output.Fungsi adalah pemetaan di mana setiap masukan di domain memiliki tepat satu keluaran. \[\text{one-one mapping } \checkmark \qquad \text{many-one mapping } \checkmark \qquad \text{one-many } \times \qquad \text{many-many } \times\] Only one-one and many-one mappings are functions.Hanya pemetaan satu-satu dan banyak-satu yang merupakan fungsi.

✒️ Function Notation Notasi Fungsi

The function "multiply by 2 then add 1" can be written in two ways:Fungsi "kalikan 2 lalu tambah 1" dapat ditulis dengan dua cara:

\[f(x) = 2x+1 \qquad \text{or} \qquad f : x \mapsto 2x+1\]

We read \(f : x \mapsto 2x+1\) as "\(f\) maps \(x\) to \(2x+1\)". We also state the domain, for example \(\text{for } x\in\mathbb{R}\) (all real numbers).Kita membaca \(f : x \mapsto 2x+1\) sebagai "\(f\) memetakan \(x\) ke \(2x+1\)". Kita juga menyatakan domainnya, misalnya \(\text{untuk } x\in\mathbb{R}\) (semua bilangan real).

🧠

📈 Basic Graph Shapes Bentuk Dasar Grafik

Knowing the shape tells you immediately where the smallest and largest outputs are.Mengetahui bentuk grafik langsung memberi tahu di mana keluaran terkecil dan terbesar.

🟦 Completing the Square Melengkapkan Kuadrat

Main formula (for \(a=1\)):Rumus utama (untuk \(a=1\)):

\[x^2+bx+c=\left(x+\frac{b}{2}\right)^2-\left(\frac{b}{2}\right)^2+c\]

General formula:Rumus umum:

\[ax^2+bx+c=a\left(x+\frac{b}{2a}\right)^2+c-\frac{b^2}{4a}\]
Turning point (vertex) Titik balik (puncak) For \(y=a(x+p)^2+q\): the vertex is \((-p,\ q)\).Untuk \(y=a(x+p)^2+q\): titik puncaknya \((-p,\ q)\).
  • If \(a\gt 0\): the graph is ∪-shaped, minimum value \(q\), so \(y\ge q\).Jika \(a\gt 0\): grafik terbuka ke atas (∪), nilai minimum \(q\), jadi \(y\ge q\).
  • If \(a\lt 0\): the graph is ∩-shaped, maximum value \(q\), so \(y\le q\).Jika \(a\lt 0\): grafik terbuka ke bawah (∩), nilai maksimum \(q\), jadi \(y\le q\).
Reason: \((x+p)^2\ge 0\) for every \(x\), and it equals \(0\) when \(x=-p\).Alasan: \((x+p)^2\ge 0\) untuk setiap \(x\), dan bernilai \(0\) ketika \(x=-p\).

Example: \(x^2-4x+1\)Contoh: \(x^2-4x+1\)

\[x^2-4x+1=(x-2)^2-4+1=(x-2)^2-3 \;\Rightarrow\; \text{vertex } (2,-3),\ \text{minimum } -3\]

⚫⚪ Closed and Open End Points Titik Ujung Tertutup dan Terbuka

⚫ Closed dot: \(\le\) or \(\ge\)The end value IS included. Example: \(-3\le x\le 2\).Nilai ujung TERMASUK. Contoh: \(-3\le x\le 2\).
⚪ Open dot: \(\lt\) or \(\gt\)The end value is NOT included. Example: \(x\gt 8\Rightarrow f(x)\gt 12\).Nilai ujung TIDAK termasuk. Contoh: \(x\gt 8\Rightarrow f(x)\gt 12\).

4. Problem IntroductionPengenalan Masalah

Two big questions: Is it a function? and What is its range?Dua pertanyaan besar: Apakah ini fungsi? dan Berapa range-nya?

🧩

❓ Question 1: Is the graph a function? Pertanyaan 1: Apakah grafik ini fungsi?

📏 Vertical line test Uji garis vertikal If every vertical line cuts the graph at most once, the graph is a function. If one vertical line cuts it twice or more, one input has two outputs → NOT a function.Jika setiap garis vertikal memotong grafik paling banyak sekali, grafik itu fungsi. Jika ada garis vertikal yang memotong dua kali atau lebih, satu masukan punya dua keluaran → BUKAN fungsi.
📐 Horizontal line test (for functions only) Uji garis horizontal (khusus fungsi) If every horizontal line cuts the graph at most once → one-one. If some horizontal line cuts it twice or more → many-one.Jika setiap garis horizontal memotong grafik paling banyak sekali → satu-satu. Jika ada garis horizontal yang memotong dua kali atau lebih → banyak-satu.
\(y=x^2\): vertical line cuts once ✓ function; horizontal line cuts twice → many-onegaris vertikal memotong sekali ✓ fungsi; garis horizontal memotong dua kali → banyak-satu
\(y=x^3\): both lines cut once → one-one functionkedua garis memotong sekali → fungsi satu-satu
\(y^2=4x\): vertical line cuts twice → NOT a functiongaris vertikal memotong dua kali → BUKAN fungsi

❓ Question 2: What is the range? Pertanyaan 2: Berapa range-nya?

Problem: Find the range of \(f(x)=x^2-4x+1\) for \(0\le x\le 5\).Masalah: Tentukan range dari \(f(x)=x^2-4x+1\) untuk \(0\le x\le 5\).

⚠️ A common trap Jebakan umum Many students only substitute the end points: \(f(0)=1\) and \(f(5)=6\), then write \(1\le f(x)\le 6\). This is WRONG, because the graph dips down to \(-3\) at \(x=2\)!Banyak siswa hanya mensubstitusi titik ujung: \(f(0)=1\) dan \(f(5)=6\), lalu menulis \(1\le f(x)\le 6\). Ini SALAH, karena grafik turun sampai \(-3\) di \(x=2\)!
The lowest point is the vertex \((2,-3)\), not an end point.Titik terendah adalah puncak \((2,-3)\), bukan titik ujung.
🗝️ 4-Step Method for the Range Metode 4 Langkah Mencari Range
  1. Sketch / complete the square to know the shape.Sketsa / lengkapkan kuadrat untuk mengetahui bentuk grafik.
  2. Find the turning point and check whether its \(x\)-value lies inside the domain.Cari titik balik dan periksa apakah nilai \(x\)-nya berada di dalam domain.
  3. Evaluate the end points of the domain.Hitung nilai di titik ujung domain.
  4. Choose the smallest and largest outputs and use \(\le\) / \(\lt\) correctly.Pilih keluaran terkecil dan terbesar lalu gunakan \(\le\) / \(\lt\) dengan tepat.

🧱 Piecewise functions Fungsi sepotong-sepotong

A function can be defined by different rules on different parts of the domain. Where two parts meet, check the shared \(x\)-value:Sebuah fungsi dapat didefinisikan dengan aturan berbeda di bagian domain yang berbeda. Di tempat dua bagian bertemu, periksa nilai \(x\) yang sama:

  • Both rules give the same output → still a function ✓Kedua aturan memberi keluaran yang sama → tetap fungsi ✓
  • The rules give different outputs → one input has two outputs → NOT a function ✗Aturan memberi keluaran berbeda → satu masukan punya dua keluaran → BUKAN fungsi ✗

🚫 Largest possible domain Domain terbesar yang mungkin

Start with all real numbers and remove the values that are not allowed:Mulai dari semua bilangan real, lalu buang nilai yang tidak diperbolehkan:

➗ Division by zero Pembagian dengan nol\(\dfrac{1}{x-2}\): need \(x-2\ne 0\Rightarrow x\ne 2\).Syarat \(x-2\ne 0\Rightarrow x\ne 2\).
√ Square root of a negative Akar dari bilangan negatif\(\sqrt{x-3}\): need \(x-3\ge 0\Rightarrow x\ge 3\).Syarat \(x-3\ge 0\Rightarrow x\ge 3\).

Worked Example 1 Contoh Soal 1

Is \(f(x)=x^2+1\) for \(x\in\mathbb{R}\) a one-one or a many-one function? What if the domain is \(x\ge 0\)?Apakah \(f(x)=x^2+1\) untuk \(x\in\mathbb{R}\) fungsi satu-satu atau banyak-satu? Bagaimana jika domainnya \(x\ge 0\)?

Step 1: Try two different inputs: \(f(2)=2^2+1=5\) and \(f(-2)=(-2)^2+1=5\).Langkah 1: Coba dua masukan berbeda: \(f(2)=5\) dan \(f(-2)=5\).
Step 2: Two different inputs give the same output, so the horizontal line \(y=5\) cuts the graph twice.Langkah 2: Dua masukan berbeda memberi keluaran sama, jadi garis horizontal \(y=5\) memotong grafik dua kali.
Step 3: Each \(x\) still has only one output, so it is a function → many-one functionLangkah 3: Setiap \(x\) tetap punya satu keluaran, jadi ini fungsi → fungsi banyak-satu.
Step 4: If \(x\ge 0\), only the right half of the parabola remains; it is always increasing, so every horizontal line cuts at most once → one-one functionLangkah 4: Jika \(x\ge 0\), hanya setengah kanan parabola yang tersisa; grafik selalu naik, sehingga setiap garis horizontal memotong paling banyak sekali → fungsi satu-satu.

Worked Example 2 Contoh Soal 2

Find the range of \(f(x)=x^2-4x+1\) for \(0\le x\le 5\).Tentukan range dari \(f(x)=x^2-4x+1\) untuk \(0\le x\le 5\).

Step 1 — Complete the square: \(x^2-4x+1=(x-2)^2-4+1=(x-2)^2-3\).Langkah 1 — Lengkapkan kuadrat.
Step 2 — Turning point: vertex \((2,-3)\), a minimum (\(a=1\gt 0\)). Is \(x=2\) inside \(0\le x\le 5\)? Yes ✓, so the minimum value is \(-3\).Langkah 2 — Titik balik: puncak \((2,-3)\), minimum. Apakah \(x=2\) di dalam \(0\le x\le 5\)? Ya ✓, jadi nilai minimumnya \(-3\).
Step 3 — End points: \(f(0)=0-0+1=1\), \(f(5)=25-20+1=6\).Langkah 3 — Titik ujung: \(f(0)=1\), \(f(5)=6\).
Step 4 — Compare: smallest \(-3\), largest \(6\) → \(-3\le f(x)\le 6\)Langkah 4 — Bandingkan: terkecil \(-3\), terbesar \(6\).

Worked Example 3 Contoh Soal 3

Express \(f(x)=2x^2+12x+7\) in the form \(a(x+b)^2+c\) and state the range for \(x\in\mathbb{R}\).Nyatakan \(f(x)=2x^2+12x+7\) dalam bentuk \(a(x+b)^2+c\) dan tentukan range-nya untuk \(x\in\mathbb{R}\).

Step 1 — Factor out \(a=2\) from the \(x\)-terms: \(2(x^2+6x)+7\).Langkah 1 — Keluarkan \(a=2\) dari suku-suku \(x\).
Step 2 — Complete the square inside: \(x^2+6x=(x+3)^2-9\).Langkah 2 — Lengkapkan kuadrat di dalam kurung.
Step 3 — Expand back: \(2\left[(x+3)^2-9\right]+7=2(x+3)^2-18+7=2(x+3)^2-11\).Langkah 3 — Kalikan kembali.
Step 4 — Range: \(2(x+3)^2\ge 0\), so \(f(x)\ge -11\) → \(a=2,\ b=3,\ c=-11;\ f(x)\ge -11\)Langkah 4 — Range: \(2(x+3)^2\ge 0\), jadi \(f(x)\ge -11\).

Worked Example 4 (piecewise) Contoh Soal 4 (sepotong-sepotong)

\(f(x)=\begin{cases}x+1 & 0\le x\le 2\\ 7-x^2 & 2\le x\le 3\end{cases}\). Is it a function? Find its range.Apakah ini fungsi? Tentukan range-nya.

Step 1 — Check the meeting point \(x=2\): \(2+1=3\) and \(7-2^2=3\). Same output ✓ → it is a function.Langkah 1 — Periksa titik pertemuan \(x=2\): keluarannya sama ✓ → ini fungsi.
Step 2 — Piece 1: \(x+1\) increases from \(f(0)=1\) to \(f(2)=3\).Langkah 2 — Bagian 1: \(x+1\) naik dari 1 ke 3.
Step 3 — Piece 2: \(7-x^2\) decreases for \(x\ge 2\): from \(f(2)=3\) to \(f(3)=7-9=-2\).Langkah 3 — Bagian 2: \(7-x^2\) turun untuk \(x\ge 2\): dari 3 ke \(-2\).
Step 4 — Combine: lowest \(-2\), highest \(3\) → \(-2\le f(x)\le 3\)
Langkah 4 — Gabungkan: terendah \(-2\), tertinggi \(3\).

📌 Summary Rangkuman

1. Function FungsiEvery input has exactly one output. One-one ✓, many-one ✓, one-many ✗, many-many ✗.Setiap masukan punya tepat satu keluaran. Satu-satu ✓, banyak-satu ✓, satu-banyak ✗, banyak-banyak ✗.
2. Line tests Uji garisVertical line → function? Horizontal line → one-one or many-one?Garis vertikal → fungsi? Garis horizontal → satu-satu atau banyak-satu?
3. Range method Metode rangeShape → turning point (inside domain?) → end points → smallest & largest.Bentuk → titik balik (di dalam domain?) → titik ujung → terkecil & terbesar.
4. Completing the square Melengkapkan kuadrat\(a(x+b)^2+c\): if \(a\gt 0\), \(f(x)\ge c\); if \(a\lt 0\), \(f(x)\le c\).Jika \(a\gt 0\), \(f(x)\ge c\); jika \(a\lt 0\), \(f(x)\le c\).
5. Largest domain Domain terbesarExclude division by zero and square roots of negatives.Buang pembagian dengan nol dan akar bilangan negatif.
6. Piecewise Sepotong-sepotongSame output at the joining \(x\) → function; different outputs → not a function.Keluaran sama di titik sambung → fungsi; berbeda → bukan fungsi.

⚠️ Common Mistakes Kesalahan Umum

  • Using only the end points when the turning point is inside the domain.Hanya memakai titik ujung padahal titik balik ada di dalam domain.
  • Writing \(\ge\) when the domain uses \(\gt\) (e.g. \(x\gt 8\Rightarrow f(x)\gt 12\), not \(\ge\)).Menulis \(\ge\) padahal domain memakai \(\gt\).
  • Writing \(2^x\ge 0\) instead of \(2^x\gt 0\).Menulis \(2^x\ge 0\) padahal seharusnya \(2^x\gt 0\).
  • Forgetting to multiply the constant back when \(a\ne 1\) in completing the square.Lupa mengalikan kembali konstanta saat \(a\ne 1\) dalam melengkapkan kuadrat.
